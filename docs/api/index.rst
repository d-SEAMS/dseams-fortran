API reference
=============

Two references sit side by side.

The narrative page is kinds, ownership, errors, and the cubic-ice
census. The symbol pages are generated by FORD from the Fortran
sources: every public parameter, type, type-bound procedure and
module procedure of ``seams``, ``seams_c`` and ``seams_kinds``.
``docs/check_api_coverage.py`` fails the docs build when one of those
symbols has no page.

.. toctree::
   :maxdepth: 1

   fortran

After ``python3 docs/assemble_site.py`` the generated pages are
beside this one:

* `seams <generated/module/seams.html>`_ is the module a program uses.
* `seams_c <generated/module/seams_c.html>`_ is the ``iso_c_binding``
  image of ``include/seams.h``.
* `seams_kinds <generated/module/seams_kinds.html>`_ holds
  ``seams_real`` and ``seams_int``.
* `Procedures <generated/lists/procedures.html>`_ and
  `derived types <generated/lists/types.html>`_ are the indexes.

The C API those procedures bind is
`docs.dseams.info <https://docs.dseams.info/reference/api.html>`_.
